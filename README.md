# 一方水土

地方主政者生涯模拟，单文件 HTML，复刻《置身事内》（现《设身处地》）的核心玩法，全部文本和数值为原创。

- `index.html` — 游戏本体，双击即玩，本地自动存档
- `assets/` — 美术资产（WebP，游戏实际读取的版本，共 35 张约 6MB）；`assets/原图/` 是 GPT 出的 PNG 原图（约 70MB，不进 git）。缺图自动留白
- `manifest.webmanifest` + `assets/icon/` — 应用图标（朱砂印章「一方水土」），添加到手机桌面后按独立应用打开
- `docs/美术资产清单.md` — 35 张图的清单与出图 prompt

## v1.11 存档兼容与规则

- 继续使用 `yifang_save`。读取或导入旧存档时，新增台账与字段，不重置现金、土地总量、债务、年龄、履历、责任档案和在建项目；已落地企业不追溯审批。

- 旧存档接入供需系统有6个月过渡，期间生产系数最低90%；过渡后按实际供水供电结算。新存档直接执行供需规则。

- 水电污水按实际服务量收费，维护费仍在运转支出扣除；借债额度使用经营净收益口径，避免毛收入虚增可偿债财力。
- 普通工业片区按污染等级准入；保护区禁工业，重污染须选择重工业治理片区。镇级高污染须先取得县级审批，县级重污染须先市级会审。审批、治理、技改替换当月原行程，推进时执行，不能额外刷行动。
