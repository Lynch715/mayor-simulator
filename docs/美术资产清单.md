# 《一方水土》美术资产清单与出图 Prompt

## 一、统一风格

界面底色是文件纸 #F3F2EE，字是墨色，只有红头和印章用红。图要压得住这个调子，不能是饱和的游戏插画。

**风格定位**：钢笔线描 + 水墨淡彩，报告文学插图的感觉。线条克制，留白多，颜色只用灰、墨、赭石、一点公文红。不画脸部特写，人物中远景或侧背影，避免"像谁"。没有任何真实地名、真实标识、真实牌匾文字，画面里出现的文字一律模糊或不可读。

**全局风格前缀（每条 prompt 前面都带）**：

```
Pen-and-ink line drawing with muted watercolor wash, in the style of Chinese reportage illustration. Restrained palette: ink black, warm grey, ochre, a single accent of vermilion red. Generous white space, paper texture background (#F3F2EE), no text or signage legible, no logos, no real landmarks, no close-up faces. Quiet, documentary mood.
```

**尺寸**：横幅 1536×512（场景/城市）、立绘 768×1024（人物）、结局 1536×1024、封面 1536×1024。文件全部 PNG，放在 `assets/` 目录，文件名照清单，我接进去时按名字读。

## 八、入库状态（2026-09-06）

35 张全部入库。原 PNG 存在 `assets/原图/`，游戏读取的是同名 `.webp`（质量 82，立绘保留透明通道），总体积从 70MB 压到 6MB。要换图：把新 PNG 放进 `assets/原图/`，重新转一份同名 webp 到 `assets/` 即可，代码不用动。

接入位置与映射都在 `index.html` 的「美术资产」段（`PORTRAIT`、`SCENE`、`WIDE` 三张表 + `evArt()`）。新增事件时在表里加一行 id 即可；没映射的呈批件默认用 `s_meeting`，信访件默认 `s_petition` + `p_petitioner`，通知默认 `s_finance`。

## 九、出图时注意

- 同一批用同一个会话出，风格漂移最少；先出 `p_zhou.png` 和 `city_0.png` 定调，满意了再批量。
- 人物图如果 GPT 忍不住画正脸，追加 "seen in three-quarter profile, face partly turned away, no eye contact"。
- 画面里出现可读汉字或英文一律重出；红头文件、横幅、牌匾都要求 "unreadable / blurred text"。
- 不要让它加"游戏感"的高光和描边；出现了就加 "flat, no glow, no outline highlights"。
- 总计 35 张。接进游戏后：封面铺开局页；城市横幅在总览页顶部；呈批件左侧立绘 + 顶部场景横幅按事件 id 映射；结局图在结局页顶部；退休篇三张按年份。图缺一张也不影响运行，会自动留白。
